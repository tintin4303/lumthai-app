## 4. B. 3D Dance Pipeline
**Update the text to reflect the unified flow:**
"The 3D Dance Pipeline processes an ordered sequence of dance-pose images through a unified, fully automated workflow. 

First, MediaPipe and YOLOv8 extract body keypoints and hand landmarks. Second, the Depth Anything V2 model estimates dense relative depth maps across all frames, rendered using the Inferno colormap for intuitive visual depth inspection. Third, bidirectional Farnebäck dense optical flow generates a smooth morphed transition video between sequential poses. Finally, the complete dataset is piped to an Apple Object Capture background process utilizing the M-series Neural Engine to construct a fully textured, photorealistic 3D `.obj` statue. 

To optimize browser responsiveness and prevent WebGL context exhaustion, the user interface samples a random subset of 5 keyframes for detailed 2D visual analysis (Detection preview, Holistic Skeleton overlay, and Depth Anything V2 map). Beneath the photorealistic 3D Avatar, interactive 3D point clouds are rendered using Three.js / React Three Fiber, allowing users to orbit and inspect the volumetric 3D form of the isolated dancer (with background transparency) and the intricate 3D hand gesture."
